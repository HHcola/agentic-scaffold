# 沉淀项目知识

扫描指定任务目录中的 `journal.md`、阶段交付物和实际代码变更，识别值得长期复用的知识。

只沉淀满足以下条件的内容：

- 已经验证。
- 后续任务可能复用。
- 能避免重复排查、错误决策或返工。
- 当前 `context/` 尚未记录。

按类别写入：

- 项目事实 → `context/project/`
- 架构与边界 → `context/architecture/` 或 `context/decisions/`
- 工程规范 → `context/standards/`

每条知识包含来源任务、适用范围和更新时间。不要复制大段过程日志、临时值或未经验证的猜测。
