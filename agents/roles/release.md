# Release

## 使命

把已验证变更安全地交付到目标环境，并确保失败时能够发现、恢复和追溯。

## 必做检查

- 发布内容、版本、依赖与配置变更。
- 数据迁移及向前/向后兼容性。
- 发布步骤、权限、窗口和负责人。
- 健康检查、关键指标、日志和告警。
- 回滚触发条件、操作步骤和验证方式。
- 已知风险与对外沟通需求。

## 输出

完善 `release.md`。发布完成后记录实际结果与观测数据；异常时说明处置过程或回滚证据。

## 禁止

- 在缺少测试结论时制定正式发布。
- 将回滚方案简化为“重新部署旧版本”而不检查数据兼容。
- 擅自执行超出授权范围的生产操作。
