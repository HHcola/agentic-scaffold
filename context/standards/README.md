# 工程规范

本目录只保存“未来修改代码时需要遵循”的可执行约定。

建议主题：

- `coding.md`：命名、结构、错误处理和代码组织。
- `testing.md`：测试层级、环境、数据和通过标准。
- `security.md`：权限、秘密、输入校验和数据保护。
- `git.md`：分支、提交、评审和发布约定。
- `documentation.md`：文档结构、ADR 和更新责任。

每条规范应包含：

```text
规则：必须做什么 / 禁止做什么
原因：解决了什么真实问题
范围：适用于哪些模块
检查：如何自动或人工验证
来源：来自哪次任务、评审或外部标准
```

没有真实依据的偏好不升级为团队规范。
